## What it does

`main.py` (Python 3, standard library only) writes a single deadpan excuse —
a robot vacuum explaining why it missed a spot — to `/output/entry.txt`.
The line is at most 200 characters, one line, non-blank, and validated
before it is written.

## The line

> I have vacuumed that corner nine times. The dust there has filed for
> tenancy, pays rent in crumbs, and legally outranks me now.

(127 characters.)

## Run

```sh
python3 main.py
cat /output/entry.txt
```
